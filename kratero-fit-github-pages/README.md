## Cómo publicarlo (sin usar terminal)
1. Crea un repo nuevo en https://github.com/new (público, sin README).
2. Add file → Upload files → arrastra TODO el contenido de esta
   carpeta ya descomprimida (no el .zip) → Commit changes.
3. Settings → Pages → Source: rama main, carpeta /(root) → Save.
4. En 1-2 minutos: https://tu-usuario.github.io/kratero-fit/
